<h1 align="center"> Juego del Amigo Secreto </h1>

<h2>Descripción del Proyecto</h2>
<p>Como parte del desarrollo de la formación de Alura latam y Oracle One, desarrole este challenge del juego del amigo secreto donde podemos ingresar los nombres de nuestro amigos y sortear uno de los nombre. </p>

<h2>Estado del Proyecto</h2>
<p>Con el cargue de los archivos a este repositorio se da por culminado el desarrollo del juego del amigo secreto.</p>

<h2>Características</h2>
<p>Este proyecto cuenta con diferentes validadores que ayudar a orientar al usuario para que use correctamente el juego, además de ello se tiene en cuenta actualización de las listas y el borrado de la lista una vez termina el juego.</p>
